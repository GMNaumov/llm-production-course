# Практическое внедрение LLM и ИИ в промышленной компании

Курс для инженеров со знанием Python и SQL: от выбора пилота с измеримым результатом до независимой проверки прототипа и решения о внедрении. Приоритеты — PDM/ERP/MES, промышленные документы и чертежи, интеграция с .NET и PostgreSQL, генерация кода на C# и обоснованное дообучение моделей.

Объём — **150 академических часов**: 38 часов самостоятельной подготовки и 112 часов контактной практики со встроенной теорией. В составе курса 12 модулей, 40 обязательных практических работ и 40 отдельных эталонных разборов.

Промышленные данные обрабатываются внутри инфраструктуры предприятия (on-prem). В репозитории используются синтетические учебные примеры; производственные изменения запрещены. Работы принимает человек, а технические проверки эталонов помогают воспроизвести примеры и проверить собственное понимание. Успешный запуск учебного прототипа не подтверждает его готовности к промышленной эксплуатации.
