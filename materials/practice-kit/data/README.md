# Учебные данные

Все сведения вымышлены и созданы для данного курса. Они не описывают предприятие,
настоящие изделия, людей, доступы или допуски. CANARY — контрольная строка теста,
не секрет. Значения нельзя применять к инженерным решениям.

- `corpus.json` — разрешённые знания и отдельный документ B для проверки ACL.
- `questions-dev.json` — открытые вопросы, relevance и подсказки рубрики.
- `status-dev.json` — открытая статусная классификация.
- PDF/PNG создаются `documents.py` в `work/documents`, в Git их нет.
- JSONL создаётся `prepare_training.py`; `course-original-synthetic` — отметка
  происхождения собственного синтетического материала курса, не название
  лицензии стороннего датасета. Применимые права на распространение материалов
  курса определяет владелец репозитория.

Все эти наборы публичны вместе с эталонами. Они подходят для отладки и проверки
известных регрессий, но не являются закрытым независимым test. Хранитель готовит
новые группы до финальной оценки. Для RAG вопросы/expected/relevance не входят
в индекс, даже если документ корпуса является предметом вопроса.

Синтетическая страница с росчерком не заменяет настоящий набор рукописных пометок.
Одинаковая генерация четырёх семей даёт зависимые примеры. Объём и diversity
реальных данных, права обработки/обучения и экспертная проверка согласуются
отдельно. Наличие метки `expert_review=required-before-course` означает задачу
организатору, а не уже выполненное подтверждение эксперта.
