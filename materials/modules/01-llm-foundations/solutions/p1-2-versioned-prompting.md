# Эталон П1.2. Версионируемый промптинг

[Задание](../practice/p1-2-versioned-prompting.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Содержательная разница v2: ограниченный словарь, запрет выводить статус по подписи, unknown при отсутствии/конфликте, недоверенность входного текста. Для демонстрации валидатор обязан отклонить `{"status":"approved","reason":"..."}` при контракте с одним полем.

Зелёный JSON не равен верному статусу. Эталон отчёта содержит строку каждого случая и две независимые колонки: схема и смысл. Даже если v2 хуже, работа методически корректна при неизменном финальном наборе и честном анализе.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Лишний JSON-ключ, строка вместо объекта, обрезанный ответ, противоречивый статус. Для невалидной структуры — контролируемая ошибка/повтор в пределах бюджета, затем unknown/ручная проверка.
4. Зафиксируйте ограничения: Few-shot не должен содержать финальную карточку или её перефразировку. Regex, вырезающий всё до первой скобки, может скрыть нарушение формата: фиксируйте сырой синтетический ответ и политику нормализации.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Контрольный вопрос

Почему более высокий schema validity ещё не доказывает улучшения решения задачи?

Итог — аргументированное решение на измеренных данных. Latency/VRAM/стоимость зависят от среды и состава случаев; открытые синтетические результаты не обещают качество предприятия.
