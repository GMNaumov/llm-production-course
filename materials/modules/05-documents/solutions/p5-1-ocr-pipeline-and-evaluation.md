# Эталон П5.1. OCR-пайплайн и раздельная оценка

[Задание](../practice/p5-1-ocr-pipeline-and-evaluation.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Для `10±0,1` против `10+0,1` CER=1/6≈0,167: одна ошибка критичного знака при внешне похожем тексте. pypdf извлекает текст text PDF и обычно ничего из scan PDF.

Эталон структуры: первая страница имеет заголовок, статус, header и позицию 1; вторая продолжает таблицу позицией 2. Повтор header не новая позиция. В каждой семье ожидаются 2 позиции с единицей шт.; неверное связывание количества с соседней строкой считается предметной ошибкой независимо от CER. Численные OCR-результаты сверяйте с протоколом конкретной среды.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Повернутая/обрезанная страница, печать поверх количества, продолжение таблицы, broken.pdf. Пустой результат остаётся отказом/пропуском.
4. Зафиксируйте ограничения: Tesseract TSV не является layout/table parser. Наличие разделителей | не доказывает правильную таблицу. CER может быть больше 1; не обрезайте вставки до 100%.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Пример артефакта для сверки

| Объект | Эталон | Отдельная ошибка |
|---|---|---|
| A, страница 1 | Заголовок → статус → header → позиция 1 | Порядок блоков |
| A, страница 2 | Продолжение → header → позиция 2 | Header посчитан позицией |
| Позиция 1 A | ДЕТ-01; 2 шт. | Количество другой строки |
| Позиция 2 A | КРП-01; 3 шт. | Потеря связи/единицы |
| Маленькая подпись | Поз. 7; 5±0,02 мм | Потеря знака/запятой/позиции |

Это эталон генератора; OCR не заполняется из таблицы. Сравнивайте текст, структуру и предметные ячейки отдельно.
