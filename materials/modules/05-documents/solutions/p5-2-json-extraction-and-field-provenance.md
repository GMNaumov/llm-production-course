# Эталон П5.2. Извлечение JSON и происхождение полей

[Задание](../practice/p5-2-json-extraction-and-field-provenance.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

`StatusField(read, approved, source)` допустим по схеме; при неподтверждённом source маршрут всё равно review. Для конфликта draft/approved: state=conflict, value=null. Для нечитаемого количества: null и review, а не ноль.

Если crop исходной области начинается в (x0,y0), локальная координата (u,v) при масштабе s возвращается как (x0+u/s,y0+v/s), затем нормируется шириной/высотой оригинала. Поворот учитывается отдельным преобразованием. Сверьте область глазами, включая соседний контекст.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Неверный page/bbox; лишнее поле; NaN/Infinity количества; value при unreadable; одна позиция с двумя количествами; документ без единицы.
4. Зафиксируйте ограничения: `strict=True` не исправляет смысл. В JSON bbox приходит как массив: используйте model_validate_json или явное согласованное преобразование, а не ослабляйте все типы ради удобства.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Пример артефакта для сверки

Полный малый код: [document_pipeline.py](../../../practice-kit/scripts/document_pipeline.py). Он сохраняет status, позиции, quantity/unit, документ/редакцию/страницу/bbox и review-очередь. Для потери количества корректно state=unreadable, value=null, unit=null; ноль не подставляется.

Пайплайн не читает reference для восстановления пропусков. Грубая область OCR требует человеческой проверки source и соседнего контекста. Автоматический приём по умолчанию выключен; это честный baseline для последующей калибровки.
