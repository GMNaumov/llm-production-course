# Эталон П2.1. Preflight и GPU-проброс

[Задание](../practice/p2-1-preflight-and-gpu.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Эталон цепочки доказательств: Docker server Linux → GPU видна → CUDA tensor исполняется → модель загружена → /ready успешен → benchmark содержит ответы и ошибки. Числа памяти записываются с текущего ПК; местный протокол из комплекта не заменяет проверку RTX 3060.

Восстановление выбирают по слою: переключить согласованный context при ошибочном выборе; проверить backend/драйвер при отсутствии GPU; уменьшить модель/контекст по заранее согласованному резерву при OOM. После восстановления повторить функциональный запрос.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Неверный context; GPU не запрошена; модель превышает доступную память. Ошибку не скрывать переводом на CPU без маркировки.
4. Зафиксируйте ограничения: Команда preflight проверяет существующий образ. Если его ещё нет, организатор заранее загружает утверждённый образ. Успешный nvidia-smi без tensor/model/API не завершает preflight.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Контрольный вопрос

Почему сообщение ready после загрузки модели не гарантирует, что backward или длинный запрос поместятся в память?

Итог — аргументированное решение на измеренных данных. Latency/VRAM/стоимость зависят от среды и состава случаев; открытые синтетические результаты не обещают качество предприятия.
