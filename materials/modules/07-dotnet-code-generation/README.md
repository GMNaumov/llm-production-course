# Модуль 7. Генерация и проверка C#/.NET-кода

[Предыдущий модуль](../06-dotnet-postgresql-tools/README.md) · [Следующий модуль](../08-fine-tuning/README.md)

От контекста репозитория к проверенному C#-патчу.

**Объём:** 12 ак. ч.: 3 self-study и 9 контактной практики со встроенной теорией. Отдельные часы лекций не добавляются.

## Результаты теоретической подготовки

Устанавливать baseline сборки; выбирать разрешённый контекст; различать компиляцию, тесты, анализ и review; оценивать ручную доработку.

## Как изучать модуль

Основной [конспект теории](self-study.md) содержит маршрут в пределах self-study, объяснения, разобранные примеры кода, вопросы с пояснениями и открытые источники. Короткие вводные и обсуждение ошибок на контактном занятии используют тот же конспект. Код в Markdown демонстрирует отдельный принцип; условия запуска и ограничения указаны рядом.

Вопрос для вводного разбора: **Какие независимые проверки доказывают нужное поведение, а не только правдоподобие кода?**

## Связь теории с будущей практикой

П7.1 — репозиторий, SDK и исходные проверки; П7.2 — контракты и слои проверки; П7.3 — знаменатели и полное время; П7.4 — зависимости, injection и секреты.

Это карта необходимых понятий. Критерии приёмки определяет [программа](../../../curriculum.md); подробные задания пока остаются заготовками и разрабатываются следующим шагом.
