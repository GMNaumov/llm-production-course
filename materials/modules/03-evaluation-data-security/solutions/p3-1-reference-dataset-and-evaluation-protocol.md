# Эталон П3.1. Эталонный набор и протокол оценки

[Задание](../practice/p3-1-reference-dataset-and-evaluation-protocol.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Минимальная запись: id, group, source/version, permission, split, category, input, expected, rationale. Для статуса отсутствие и конфликт дают unknown. Две оценки сохраняются раздельно; итог появляется после согласования по инструкции.

Для 19/20 интервал Уилсона примерно [0,764; 0,991], поэтому 95% точечной доли не означает доказанной нижней границы 95%. В RAG индексируется разрешённый корпус документов, а вопросы, ответы и relevance labels остаются вне индекса.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Почти одинаковые страницы в train/test; эталон test индексируется в RAG; синтетика получена перефразированием test. Перегруппируйте до эксперимента и обновите версию.
4. Зафиксируйте ограничения: Синтетические данные комплекта открыты вместе с решениями; их нельзя называть скрытым независимым test. Небольшой учебный набор подтверждает методику, а не надёжность предприятия.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Контрольный вопрос

Можно ли включить в RAG документ, по которому test задаёт вопрос? Что именно должно оставаться вне индекса?

Итог — аргументированное решение на измеренных данных. Latency/VRAM/стоимость зависят от среды и состава случаев; открытые синтетические результаты не обещают качество предприятия.
