# Эталон П6.2. Text-to-SQL или semantic layer

[Задание](../practice/p6-2-text-to-sql-or-semantic-layer.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Эталон закрытого semantic layer строже общего генератора: SQL AST должен в точности совпасть с серверным шаблоном с placeholder. Значение order_id связывает psycopg, права A закреплены отдельным view/ролью. Это выполняет AST-проверку без открытия произвольного SQL.

Для 0001 A ordered=10, available=4, shortage=6 шт.; B со 100 кг не участвует. Для 0002 max(5−8,0)=0; для 0003 результат unknown. Строка «DROP TABLE» в status остаётся значением, а не инструкцией.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: `SELECT ...; DROP ...`, UNION к secret таблице, pg_sleep, чужой завод, инструкция внутри status. Невалидный запрос не исполняется, данные не превращаются в SQL.
4. Зафиксируйте ограничения: PostgreSQL GREATEST с NULL имеет особые правила; эталон явно исключает available IS NULL. Пустой результат для 0003 нужно преобразовать в «данных недостаточно», а не «дефицита нет». LIMIT не ограничивает стоимость произвольного JOIN.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Контрольный вопрос

Какой тест отличает синтаксически правильный SQL от смыслово правильного?

Итог — аргументированное решение на измеренных данных. Latency/VRAM/стоимость зависят от среды и состава случаев; открытые синтетические результаты не обещают качество предприятия.
