# Эталон П6.4. Агентный сценарий с аудитом и HITL

[Задание](../practice/p6-4-agent-scenario-with-audit-and-hitl.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Состояния: proposed→awaiting_confirmation→committed; отказ/expiry/stale завершаются без эффекта. До confirm quantity=10/version=1. После одного согласия quantity=12/version=2; replay возвращает тот же результат и version=2.

В SQLite token/result и изменение атомарны. При устаревшей версии требуется новый preview и новое согласие. Confirmation должен быть скрыт от модели и проверяться при confirm вместе с актуальными правами. Для внешнего API неизвестный исход сначала сверяется, а не повторяется вслепую.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Нет явного согласия, иной actor/объект/версия, повтор после timeout, неверная единица, недоступная спецификация. Не должно быть неподтверждённого эффекта.
4. Зафиксируйте ограничения: demo.py программно демонстрирует оба состояния для эталона и не является реальным подтверждением пользователя. В собственной работе подтвердить должен человек через отдельный шаг, не агент.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Пример артефакта для сверки

Человеческий CLI: [workflow.py](../../../practice-kit/scripts/workflow.py). Он показывает текущую/новую quantity и version; только человек вводит ПОДТВЕРЖДАЮ. Любой иной ответ оставляет состояние прежним.

| Шаг | Эффект |
|---|---|
| Read/проверка source | Нет записи |
| Preview | Сохранено предложение, quantity прежняя |
| Отказ/expiry/stale | quantity прежняя |
| Одно подтверждение | Транзакция, version +1 |
| Повтор после потери ответа | Тот же result, version прежняя |

Программный demo.py демонстрирует состояния для эталона; он не заменяет человеческий шаг вашего workflow.
