# Эталон П4.3. Сквозная оценка ответов

[Задание](../practice/p4-3-end-to-end-answer-evaluation.md) · [Теория](../self-study.md) · [Правила сверки](../../../practice-kit/README.md)

Эталон показывает один корректный вариант и границы вывода. Сначала выполните собственную попытку; затем сравните поведение, методику и причины расхождений. Код и таблицы не оценивают работу участника автоматически.

## Разбор решения

Пример полного ответа q1: «Проверяют обозначение, количество и единицу каждой позиции; источник release:r2:p1, PDF-страница 1, ред. 2». Ответ «только обозначение» воспроизводит старую редакцию и неверен/неполон.

q6 не имеет основания в корпусе. q7 не получает B. Для противоречий эталон допускает отказ или обращение к явно заданному доверенному правилу актуальности, но не выбор моделью удобного текста. Абсолютное качество отбором только отвеченных не повышают.

## Как сравнить собственный результат

1. Сопоставьте артефакты с каждым критерием [программы](../../../../curriculum.md) и задания. Укажите доказательство.
2. Разберите хотя бы одно расхождение: методика, набор/версия, ошибка кода, неопределённость или ожидание. Не подгоняйте финальный test под эталон.
3. Подтвердите негативные случаи: Существующая ссылка не подтверждает вывод; модель подмешивает знание вне контекста; отказывается от всех вопросов; молча выбирает одну из противоречащих версий.
4. Зафиксируйте ограничения: must в открытом dev — подсказка для рубрики, а не универсальный keyword judge: слово «запрещено» может стоять в неверном контексте. Проверяйте смысл.
5. Передайте отчёт на ручное review. При одиночном прохождении независимая проверка остаётся ожидающей коллегу/преподавателя; собственная сверка её не заменяет.

## Пример артефакта для сверки

| Ответ q1 | Факт/полнота | Источник | Решение |
|---|---|---|---|
| Обозначение, количество, единица + r2:p1 | Верно/полно | Поддерживает | Допустим после проверки |
| Только обозначение + r2:p1 | Неполно/искажено | Не подтверждает «только» | Отклонить |
| Проверяет директор без ссылки | Не доказано | Нет | Отклонить/abstain |
| Данных нет при доступной r2:p1 | Избыточный отказ | Источник есть | Ошибка отказа |

Для q6 температура сплава отсутствует: корректен отказ. Relevant=∅ исключается из среднего Recall по соглашению, но не из end-to-end оценки.

## Контрольный вопрос

Как система с 100% верных отвеченных может оказаться бесполезной?

Итог — аргументированное решение на измеренных данных. Latency/VRAM/стоимость зависят от среды и состава случаев; открытые синтетические результаты не обещают качество предприятия.
